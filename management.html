⚙️ Konfigurasi AI ▼

🌐 Terjemahan Lirik ▼

Toggle hanya menampilkan/menyembunyikan terjemahan. AI tetap menerjemahkan ke bahasa pilihan di atas dan hasilnya disimpan bersama liriknya — berapa pun status toggle-nya.

📖 Cara Penggunaan ▼

  1. Buka tab YouTube, putar video musik apa pun, lalu klik ikon ekstensi di toolbar untuk menampilkan widget lirik.
  2. Ekstensi otomatis mencari lirik bertimestamp di LRCLIB. Jika API key AI diisi dan lagu berbahasa asing, teks ditransliterasi ke romaji oleh Gemini (fallback ke 9Router).
  3. Terjemahan per baris: pilih English / Indonesia di bagian 🌐 Terjemahan Lirik. AI selalu menerjemahkan ke bahasa tersebut dan menyimpan hasilnya ke penyimpanan lokal; toggle ON/OFF hanya menampilkan atau menyembunyikan terjemahan di widget. Tombol Terj: ON/OFF di header widget mempercepat toggle yang sama.
  4. Jika LRCLIB tidak punya lagunya, ekstensi fallback ke scraping Kazelyrics. Bila Gemini atau 9Router dikonfigurasi, lirik dirapikan AI (Gemini → 9Router); tanpa API key, lirik mentah ditampilkan.
  5. Saat video diputar, baris lirik tersorot otomatis mengikuti waktu (karaoke) dan bisa di-scroll manual tanpa mengganggu sinkronisasi.
  6. Tombol −0.1s / +0.1s menyesuaikan offset waktu; Reset mengembalikan ke 0. Offset tersimpan permanen.
  7. Tombol 🔗 memuat lirik dari URL LRCLIB (bentuk: https://lrclib.net/tracks/ID), berguna jika judul video berbeda dari judul lagu.
  8. Sinkron antar-tab: hanya satu tab yang bersuara yang menjadi sumber waktu — lirik di tab lain mengikuti.
  9. Lirik hasil proses disimpan otomatis ke penyimpanan lokal dan dimuat ulang tanpa internet di putaran berikutnya.
  10. Klik tombol ⚙️ di header widget untuk membuka halaman ini: kelola lirik tersimpan, konfigurasi API Gemini/9Router, dan hapus data.
  11. Kustomisasi UI: atur warna background, tingkat transparan, warna lirik aktif/pasif, warna romaji, dan ukuran font lewat bagian Konfigurasi Tampilan Widget.
  12. Konfigurasi API di atas disimpan di penyimpanan lokal browser dan dipakai untuk semua pemrosesan AI (romaji, terjemahan, formatting, dan fallback). Kedua API key bersifat opsional.
  13. Panduan API: dapatkan Gemini API key gratis di Google AI Studio. Untuk 9Router lokal (port default 20128), isi URL ke http://localhost:20128/v1/chat/completions atau http://127.0.0.1:20128/v1/chat/completions.
  14. Untuk development, ubah DEBUG di background.js menjadi true agar log muncul di console. Sebelum push, ubah kembali ke false.
  15. Proyek independen. Lirik sinkron didukung oleh LRCLIB — Free & Open Lyrics Library (GitHub).
